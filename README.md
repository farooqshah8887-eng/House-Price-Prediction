# House Price Prediction

## Project Overview
This project focuses on predicting house prices using machine learning techniques. The objective is to understand the factors influencing house prices and build a model that estimates property prices based on available features.

## Objectives
- Perform exploratory data analysis (EDA).
- Analyze relationships between house features and prices.
- Prepare data for machine learning.
- Build and evaluate regression models.
- Identify important features affecting house prices.

## Dataset
The dataset is provided in `data.csv`.

It contains property-related features used to explore and predict house prices.

## Project Workflow
1. Data Loading
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Bivariate Analysis
5. Feature Engineering
6. Model Building
7. Model Evaluation
8. Feature Importance Analysis

## Exploratory Data Analysis
The project includes:
- Categorical feature analysis
- Numerical feature analysis
- Bivariate visualizations
- Feature importance visualization

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Files
- `Final_House_Price_Prediction.ipynb` — Main project notebook

- `bivariate_numeric_page*.png` — Numerical analysis visualizations

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open `Final_House_Price_Prediction.ipynb` in Jupyter Notebook.
4. Run the notebook cells sequentially.
